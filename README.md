Corenexis is a technology company building developer infrastructure and secure applications. We ship production APIs, authentication infrastructure, and consumer apps — and we build AI automation and web systems for businesses.

## What we build

### Corenexis API Platform — [api.corenexis.com](https://api.corenexis.com)

Nine production REST APIs. One key, one header, predictable JSON, and a permanently free tier on every API.

| API | What it does |
| --- | --- |
| Markdown to PDF | Print-ready PDF or page images, 13 typefaces, 1,000+ page documents |
| HTML to PDF | Full modern CSS, grid, flexbox, web fonts, optional JS execution |
| Image to Text (OCR) | Photos, scans and bills to text and markdown, 30+ languages |
| PDF to Text (OCR) | Scanned PDFs, tables and complex layouts, page selection |
| Email Validator | SMTP, catch-all, MX, SPF and DMARC checks with confidence scoring |
| Disposable Email Detector | Real-time detection against 146,000+ known domains |
| Image CDN | Upload by file or URL, flexible retention, global delivery |
| Image Conversion | 25+ formats including WebP, AVIF, HEIC and JPEG XL |
| QR Code &amp; Barcode | Standard QR, UPI payment QR, Code128, EAN-13, UPC-A |

### Corenexis Accounts — [accounts.corenexis.com](https://accounts.corenexis.com)

OAuth 2.0 single sign-on with two-factor authentication. Google, GitHub, Microsoft, magic links and passwords. Free for developers.

### Cashly — [cashly.corenexis.com](https://cashly.corenexis.com)

An India-first personal finance app for transactions, EMIs, debts, subscriptions and cards. Ships with a full REST API and an **MCP server**, so Claude, n8n or a custom agent can read and write your data with a key you issue and revoke.

### Corenexis Tools — [tools.corenexis.com](https://tools.corenexis.com)

25+ free, no-signup web utilities — security headers checker, DNS record checker, IP tools, encryption utilities and image helpers.
